  • OS的连接价值：用户需通过设备、操作系统作为中间连接路径，才能触达数字世界内的各类丰富服务资源。

B · 百炼平台模型训练功能分享

14:15:20 – 14:27:35（12:15） · 阿里云百炼团队纪要原文 ↗

纪要要点

  • 百炼平台核心训练能力全链路训练流程支持全模态模型适配：已完成对千问系列文本、视觉模型，万象系列图片、视频生成模型，以及语音类等所有主流模态的适配支持。
  • 端到端流程闭环：支持用户在平台内完成自定义评测集搭建、训练指标实时观测、模型免 GPU 部署、部署后效果评测的全流程操作。
  • RL 场景专属能力：针对 RL、OPD 等训练场景，提供轨迹奖励日志等多模块分析能力，训练过程可直接查看推理结果。
  • RL 训练落地路径前置配置步骤：通过百炼控制台开通可观测、Agent Box、SSH 等能力，参考官方指引文档完成 SDK 与运行环境配置。
  • 任务提交流程：完成训练数据准备、函数编写、功能测试后，通过 SDK 或 CLI 提交任务，控制台可实时查看各类观测指标。
  • 配套 Demo 体系：提供从入门到进阶的 4 套可直接运行 Demo，覆盖计算机、编码、数学竞赛、大学数学四类典型场景。
  • 核心技术架构与配套机制 五层技术架构设计架构模块组成：整体分为 CLI、控制面、训练面、执行面、观测面五大板块，各模块分工明确，支撑全流程训练需求。
  • 核心抽象设计：对 Lua 语言函数做系统化抽象，将代码依赖抽象为函数实体、沙箱部署实例，为评测部署复用奠定基础。
  • 网络与性能优化方案跨网交互优化：联合集团网络与 ADMALL 团队构建专属内网通道，用户无感知下通过内网访问百炼服务，规避公网各类弊端。
  • 弹性扩容优化：提交训练任务时自动将镜像与依赖推送至各 Region，大幅提升 Agent 弹性扩容时的启动运行性能。
  • 私有网络适配：支持训练任务指定客户 VPC，训练过程中可像访问内网服务一样调用客户侧自有资源与服务。
  • 观测与工具支撑体系监控观测能力：汇集训练引擎、LORA 等多类日志，支持训练指标、轨迹信息查询导出，打通 Agent Sample 系统实现一站式分析。

C · AI agent box 产品及落地实践分享

14:28:30 – 14:52:00（23:21） · 吴蒙凯（agent infra 架构师）＋严龙（阿里千问办公）纪要原文 ↗

纪要要点

  • 腾讯算 Agent 基建产品体系介绍Agent BOSS 核心差异化特性产品定位：为上午发布的 Agent 专属核心基建，定位为云上超级计算机，适配多类 Agent 负载场景需求。
  • 极致安全能力：采用 A 框 BM 架构实现沙箱实例间物理隔离，当前超 90% 特定 Agent 负载均选择该沙箱承载。
  • 极致弹性能力：可支撑 1000 TPS 并发请求 1-2 秒拉起，1 分钟内完成 1000 个实例启动，远超传统基建性能。
  • 场景专属设计：针对 Agent 运行特性设计专属功能，适配工具沙箱、有状态长时运行等多类负载需求。
  • BMS 产品版本矩阵容器版：深度兼容 PM 生态，基于现有应用体系做迭代演进，适配传统负载平滑迁移需求。
  • 极速版设计理念：基于 SOLO 技术封装底层复杂度，提供实例生命周期管控，向业务方提供两类接入 API。
  • BMS 极速版核心能力设计全链路安全体系：覆盖运营、网络、存储、内容、鉴权全层级隔离，请求仅调度至用户绑定沙箱，密钥出网自动替换为公钥。
  • 存储与成本优化：支持动态挂载专属存储介质，采用存算分离、空闲30-60分钟休眠机制，闲置实例恢复速度低至 1 秒内。
  • 五层缓存加速架构：从本地盘、跨机 P2P、CFS 挂载、专属 P2P 集群到远端存储分层缓存，整体命中率超 98%。
  • 千万办公 Agent 基建落地实践业务需求与前期试错业务场景：面向办公场景提供 PPT 生成、资讯收集、低代码应用搭建等能力，需满足快速响应、安全、高并发等多重要求。
  • 前期探索：初期使用第三方沙箱仅能支撑万级在线量，自建沙箱集群则存在机器利用率低、运维成本高的问题。
  • 核心落地方案实例快速创建优化：提前预置公共环境模板，维护预热沙箱池，用户接入时直接分配实例并挂载专属存储，创建耗时压缩至 1 秒内。

  • 阿里云技术的核心价值底层数据能力：依托 Authentic Lake 可高效完成多源异构数据的对接、清洗，解决企业历史遗留的多数据源口径不一致问题
  • 业务沉淀支撑：可将分散在业务人员脑中的经验、规则沉淀为可复用资产，大幅降低各类业务智能体的搭建与迭代成本
  • 当前共建落地进展：双方合作搭建的多智能体平台，已覆盖客服、营销、供应链等全业务链路 400 余个场景，落地 300 余个智能体
  • 未来发展方向夯实数据基础：持续优化底层数据质量，将现有店长助手、员工助手等成熟业务能力沉淀至统一智能体框架
